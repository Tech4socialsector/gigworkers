# Gigworkers v0.3.0 – Transaction Adjustments

**Release date:** 2026-05-05 · **Release type:** Minor · **Previous version:** v0.2.0

## Summary

Aggregators can now correct gig transactions after they are recorded, within a limit set by the
administrator, and every correction is logged. This release also adds an invoice summary,
removes the grievance portal, and fixes several permission errors.

## Highlights

- **Transaction adjustments**, with a full history of previous values.
- An **invoice summary** section on Welfare Fee Invoices.
- Permission fixes for aggregators on Aggregator and Welfare Fee Invoice records.

## Changes by module

### Gig Transactions
- A new **Adjust** action lets an aggregator correct a transaction's amount, date, external
  transaction ID or order status.
- Each adjustment keeps the previous values in an **adjustment log**.
- The number of adjustments allowed per transaction is set in **Gig Transaction Settings**.

### Welfare Fee Invoice
- A summary section shows the invoice totals at a glance.
- Aggregators can see only their own invoices.

### Aggregator Management
- Aggregators can select multiple service categories.

### Grievance Portal (removed)
- The grievance portal and its records have been removed from the application.

### Navigation
- The unused *Doctypes Flow* workspace has been removed.

## Bug fixes

- Aggregators no longer hit permission errors on their Aggregator record or on Welfare Fee
  Invoices.
- Fixed a migration error caused by the *Doctypes Flow* workspace.
- Fixed an error when Gig Transaction Settings had not been created yet.

## Technical changes

- New DocTypes: Gig Transaction Adjustment Log, Gig Transaction Settings, Aggregator Service
  Category.
- Removed DocTypes: Grievance, Grievance Reply, Grievance Category Setting, Grievance Category
  Rule; the Grievance Portal page.
- New patch: `create_default_gig_transaction_settings`.
- `pyproject.toml` now declares Frappe `>=16.0.0,<18.0.0` in the form Frappe Cloud expects.

## Breaking changes

| Change | Action required |
|---|---|
| The grievance portal and all grievance DocTypes are removed | Export any grievance data you need **before** upgrading |
| The *Doctypes Flow* workspace is removed | None |

## Upgrade instructions

```bash
bench --site <site> backup --with-files
cd apps/gigworkers && git fetch --tags && git checkout v0.3.0 && cd ../..
bench --site <site> migrate
bench build --app gigworkers
bench --site <site> clear-cache
bench restart
```

`migrate` runs `create_default_gig_transaction_settings`, which creates Gig Transaction Settings
with default values. After upgrading, check the maximum number of adjustments in **Gig Transaction
Settings**.
