# Gigworkers v0.2.0 – Welfare Fee Invoicing and Board Management

**Release date:** 2026-04-29 · **Release type:** Minor · **Previous version:** v0.1.0

## Summary

This release adds quarterly invoicing of welfare fees to aggregators, a Board Management module
for the Welfare Board's meetings, and a clearer view of each worker's welfare fund. It also adds
a grievance portal.

## Highlights

- Quarterly **Welfare Fee Invoices** for each aggregator, generated automatically, with overdue
  reminders.
- **Board Management:** board members, meeting agendas and meeting minutes.
- Welfare Fund Accounts now show the gig transactions behind each credit, plus summary cards.
- Aggregators can register for more than one service.

## Changes by module

### Welfare Fee Invoice (new)
- One invoice per aggregator per quarter, with line items for each welfare fee, a payment history
  and support for partial payments.
- Invoice statuses: Draft, Pending, Partially Paid, Fully Paid, Overdue.
- Invoices are generated automatically at 02:00 on 1 January, 1 April, 1 July and 1 October.
- A daily check marks unpaid invoices as overdue and sends reminders.

### Board Management (new)
- **Board Member**, **Board Meeting Agenda** (with agenda items and attendees) and **Board
  Meeting Minutes**.
- Minutes can be created from an agenda in one step.
- A new **Board Management** workspace.

### Grievance Portal (new)
- A grievance portal page, with grievances, replies, and category settings and rules.

### Welfare Fund Management
- Each account lists the gig transactions linked to its credits.
- The list view has summary number cards with drill-down.

### Aggregator Management
- Aggregators can register for multiple services.
- A **reason** field records why an application was rejected.

### Navigation
- Sidebar icons for the portal's workspaces.

## Bug fixes

- Amounts are no longer shown with a `$` symbol.
- Gig workers no longer hit permission errors when viewing their own records.

## Technical changes

- New DocTypes: Welfare Fee Invoice, Welfare Fee Invoice Item, Welfare Invoice Payment, Welfare
  Fund Gig Transaction; Board Member, Board Meeting Agenda, Board Meeting Minutes, Agenda Item,
  Meeting Attendee, Minutes Item; Grievance, Grievance Reply, Grievance Category Setting,
  Grievance Category Rule.
- New module: **Board Management**.
- Scheduled jobs: a quarterly invoice cron and a daily overdue-invoice check.
- New patch: `backfill_ledger_gig_transaction`.

## Breaking changes

None.

## Upgrade instructions

```bash
bench --site <site> backup --with-files
cd apps/gigworkers && git fetch --tags && git checkout v0.2.0 && cd ../..
bench --site <site> migrate
bench build --app gigworkers
bench --site <site> clear-cache
bench restart
```

`migrate` runs one patch, `backfill_ledger_gig_transaction`. It links existing welfare fund ledger
entries to their gig transactions.

Make sure the scheduler is enabled (`bench --site <site> enable-scheduler`), so that quarterly
invoices and overdue reminders run.
