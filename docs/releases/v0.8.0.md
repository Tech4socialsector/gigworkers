# Gigworkers v0.8.0 – Welfare Fee Settlement Correction

**Release date:** 2026-10-22 · **Release type:** Minor · **Previous version:** v0.7.0

## Summary

This release corrects how welfare fees are credited to workers' funds when an invoice is paid,
and simplifies gig transactions by removing the base payout, deduction and incentive fields.
Dashboard figures and role-based visibility have also been corrected.

## Highlights

- Welfare fees are credited to a worker's fund **exactly once**.
- Simpler gig transactions: the transaction amount is the payout figure.
- Corrected dashboard figures and new summary cards.

## Changes by module

### Welfare Fee Invoice and Welfare Fee Payment
- When an invoice is fully paid, its fee payments are marked *Completed*, and each worker's fund is
  credited **once**, through the fee payment.
- Invoice payments by cheque or cash are recorded as *Offline* on the fee payment. Other payment
  modes are recorded as *Online*.
- Status and amount fields on fee payments and invoices can be changed only by authorised roles.

### Gig Transactions
- The **base payout**, **deduction** and **incentives** fields have been removed. The
  transaction amount is used as the payout to the worker.

### Welfare Fund Management
- Welfare Fund Accounts show more detail about the linked gig transactions.

### Welfare Fund Withdrawals
- Review and payment fields can be changed only by authorised roles.

### Dashboards
- Corrected the dashboard statistics.
- New number cards: **My Completed Transactions** and **Total Welfare Fee Payment**.
- Users are kept on their own role's workspace sidebar.

## Bug fixes

- Fixed welfare fees being credited twice when an invoice was fully paid.
- Fixed records that were shown to the wrong roles.
- Corrected dashboard statistics.

## Technical changes

- Field-level permissions (`permlevel` 1) on status and amount fields of Welfare Fee Payment,
  Welfare Fee Invoice and Welfare Benefit Withdrawal.
- The desk override script is loaded again through `app_include_js`.

## Breaking changes

| Change | Action required |
|---|---|
| The Gig Transaction fields `base_payout`, `deduction` and `incentives` are removed | Remove these fields from API calls and import files |

## Upgrade instructions

```bash
bench --site <site> backup --with-files
cd apps/gigworkers && git fetch --tags && git checkout v0.8.0 && cd ../..
bench --site <site> migrate
bench build --app gigworkers
bench --site <site> clear-cache
bench restart
```

There are no new patches in this release. After upgrading, check a few Welfare Fund Accounts
against their invoices.
