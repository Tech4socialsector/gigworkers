# Gigworkers v0.1.0 – Welfare Portal Foundation

**Release date:** 2026-04-16 · **Release type:** Initial release · **Previous version:** None

## Summary

The first version of the Gig Workers Welfare Portal. It sets up the core of the welfare scheme:
aggregators register and are approved, gig workers are registered, aggregators record gig
transactions, a welfare fee is calculated on each transaction, and the fee is credited to the
worker's welfare fund, from which workers can request benefit withdrawals.

## Highlights

- Online registration for aggregators and gig workers.
- Aggregator approval with status emails and a registration certificate.
- A welfare rate card per service, with automatic welfare fee calculation on every transaction.
- A welfare fund account for every worker, with benefit withdrawals.
- Dashboards for administrators, aggregators and gig workers.

## Changes by module

### Aggregator Management
- Aggregator records with company, authorised-person, KYC and document details, and the services
  the aggregator offers.

### Aggregator Approval and KYC
- Applications move through **Submitted → Under Process → Approved / Rejected**.
- An **Aggregator Approval** page lists applications for review.
- Aggregators are emailed at each status change. A PDF registration certificate is attached.

### Gig Worker Management
- Gig worker records with identity, contact, bank and work details, with format checks on ID and
  contact numbers.
- A portal login is created for each gig worker.

### Service Management
- **Service Categories**, **Vehicle Types** and a **Service** rate card holding the welfare
  percentage, the welfare cap and the effective dates.
- An **Update Rate** action records rate changes in a rate log.

### Gig Transactions
- Aggregators record transactions for their gig workers.
- The welfare fee is calculated automatically as amount × welfare %, limited to the service's cap.
- Possible duplicate transactions are flagged as *Suspected duplicate*.
- Workers can confirm a transaction with a one-time password (OTP) sent by email.

### Welfare Fee Payment
- A fee payment is created for each completed transaction. When it is completed, the amount is
  credited to the worker's welfare fund.

### Welfare Fund Management
- One **Welfare Fund Account** per worker, with a ledger of every credit and debit and a running
  balance.

### Welfare Fund Withdrawals
- Workers can request Medical, Education, Emergency, Housing or Other withdrawals.
- Requests move through **Requested → Approved / Rejected → Paid**, with email updates.

### Dashboards
- An **Admin Dashboard**, an **Aggregator Dashboard** and a **Gig Worker Dashboard**.

### Reports and Analytics
- **Quarterly Welfare Compliance Report** and **Service Rate History**.

### Web Forms and Public Registration
- Public registration forms at `/aggregator-form` and `/gig-worker`.

### User Roles and Permissions
- **Aggregator** and **Gig Worker** roles. Aggregators see only their own workers and
  transactions, and gig workers see only their own records.
- Workspaces for administrators, aggregators and gig workers.

## Technical changes

- New Frappe app `gigworkers` with the **Gig Workers** module.
- Fixtures: Workspace, Role, Web Form, Number Card, Dashboard, Dashboard Chart and Report.
- GitHub Actions for server tests and linting.

## Breaking changes

None. This is the first release.

## Installation

```bash
bench get-app https://github.com/Tech4socialsector/gigworkers.git --branch v0.1.0
bench --site <site> install-app gigworkers
bench build --app gigworkers
bench restart
```

After installing, set up a default outgoing **Email Account** so that status emails and OTPs can
be sent.
