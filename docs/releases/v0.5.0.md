# Gigworkers v0.5.0 – Aggregator Approval Workflow and Aadhaar Masking

**Release date:** 2026-06-26 · **Release type:** Minor · **Previous version:** v0.4.0

## Summary

The aggregator approval process now supports clarification requests, so the Welfare Board can
ask an applicant for more information instead of rejecting the application. Aadhaar numbers are
masked on screen, the registration certificate has been redesigned, and import logs have their
own list views.

## Highlights

- **Clarification step** in aggregator approval.
- **Aadhaar masking** on gig worker records and aggregator lists.
- A redesigned **registration certificate** with the Karnataka seal.
- All amounts are shown in **Indian Rupees (₹)**.

## Changes by module

### Aggregator Approval and KYC
- New status flow: **Submitted → Under Process → Pending with Clarification → Approved**.
- The aggregator is emailed when clarification is requested. Once their response is recorded, the
  application returns to *Under Process*.
- The *Rejected* status has been removed from the flow.

### Gig Worker Management
- Aadhaar numbers are masked on the gig worker form.
- Fixed an error that could stop a gig worker record from being created.

### Aggregator Management
- Aadhaar numbers are masked in the aggregator list view.

### Certificates
- The registration certificate layout follows review feedback and includes the Karnataka seal.

### Web Forms and Public Registration
- The aggregator registration form was updated following review feedback.

### Bulk Import and Import Logs
- Gig Worker and Gig Transaction import logs have dedicated list views showing import ID, status
  and who ran the import.
- Aggregators see only their own import logs.

### Welfare Fund Management
- Amounts are shown with the ₹ symbol.

## Bug fixes

- Fixed an error that could stop a gig worker record from being created.
- Fixed transaction import issues found in review.

## Technical changes

- The Aggregator `status` options changed (see Breaking changes).
- Permission rules updated for the import logs.

## Breaking changes

| Change | Action required |
|---|---|
| The aggregator status *Rejected* is removed and *Pending with Clarification* is added | Review any aggregators still in *Rejected* and move them to a valid status |

## Upgrade instructions

```bash
bench --site <site> backup --with-files
cd apps/gigworkers && git fetch --tags && git checkout v0.5.0 && cd ../..
bench --site <site> migrate
bench build --app gigworkers
bench --site <site> clear-cache
bench restart
```

There are no new patches in this release.
